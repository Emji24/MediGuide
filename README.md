
# MediGuide: A Simple Health Information System

## Project Overview

MediGuide is a rule-based health information system
developed for IT 405 - Logic Programming.

The system uses SWI-Prolog to evaluate selected symptoms,
identify relevant health information, and recognize
predefined urgent warning signs.

## Proposed Features

- Dashboard
- Symptom Checker
- Health Information Results
- Health Library
- Health Tips
- Emergency Warnings
- About MediGuide

## Technology Stack

- SWI-Prolog
- HTML
- CSS
- JavaScript
- SWI-Prolog HTTP Server
- Git and GitHub

## Project Status

Currently under development.

## Disclaimer

MediGuide is intended for educational and informational
purposes only. It does not provide medical diagnosis,
prescribe medication, or replace professional medical care.
